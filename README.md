# 无名杀 · 神左慈移植

在新版无名杀框架中独立维护“汤圆精品包”的神左慈，并加入神左慈改、幻形和轮回。

- 当前扩展版本：**1.1.0**。
- 仓库维护者：[L-9527666](https://github.com/L-9527666)。
- 适配参考：Android 懒人包中的无名杀 **1.11.5.2**；其他版本需要重新确认兼容性。
- 本项目是一个独立武将扩展，需要配合无名杀本体使用。

## 武将与技能

| 武将 | 性别 / 势力 / 体力 | 技能 |
| --- | --- | --- |
| 神左慈 `tyj_zuoci` | 男 / 神 / 4 | 变幻（含新生）、轮回 |
| 神左慈改 `tyj_zuoci_gai` | 男 / 神 / 4 | 变幻（含新生）、幻形、轮回 |

**变幻**：受到符合条件的伤害后、进入濒死时、获救脱离濒死后或场上角色死亡后，随机展示至多三个可获得技能，选择其中一个获得。导致濒死的同一次伤害，已经在濒死分支处理后不会再因 `damageEnd` 追加发动。因此进入濒死并被救活时，进入和获救各发动一次。普通回复体力不会额外发动。

**新生**：游戏开始时，可以受到一点雷电伤害，然后回复一点体力。

**幻形**（神左慈改）：出牌阶段限一次，你可以选择一个技能失去并发动一次〖变幻〗。默认是自己的出牌阶段。选择窗口可以取消；候选排除变幻、幻形、内部辅助技能、装备和临时/额外技能，并对同名显示去重。

**轮回**（两名武将共有）：每轮游戏开始时，你可以选择以下一项执行，然后删除此项：

1. 随机获得一个觉醒技。
2. 随机获得一个使命技。
3. 随机获得一个限定技。
4. 随机获得一个主公技。

“随机获得”指从所选类别随机展示至多三个技能，再由玩家选择一个获得。每个类别每名角色每局只能成功执行一次；取消或没有候选不删除选项。获得的技能保留自身的条件与次数限制。

## 下载与安装

1. 在仓库页面点击 **Code → Download ZIP**，解压下载的文件。
2. 找到其中的 **`shenzuoci_yizhi_v2` 文件夹**。手机扩展目录名必须保持这个名字。
3. 首次安装时，将整个 `shenzuoci_yizhi_v2` 文件夹放进无名杀本体的 `extension` 目录。最终应能找到 `extension/shenzuoci_yizhi_v2/extension.js`，不要额外嵌套一层同名文件夹。
4. 完全退出并重新打开游戏，启用“神左慈移植”，再重启一次；在选将或武将搜索中查找“神左慈”和“神左慈改”。

本次适配的 Android 包名对应目录为：

```text
Android/data/com.widget.noname.zq/files/noname/extension/shenzuoci_yizhi_v2/
```

其他客户端请以自己的本体目录为准。本仓库未验证游戏内“导入 ZIP”入口；以上提供的是手动复制目录的安装方式。

更新已有安装时，先单独备份将要覆盖的文件，再替换 `extension.js`、`info.json`；只有资源发生变化才需要更新对应头像或音频。更新完成后完全重启游戏。

## 本地验证

需要 Node.js；本次整理使用 Node.js 24.17.0，无需安装 npm 依赖。在仓库根目录执行：

```sh
npm run check
npm test
```

检查包含入口语法、版本一致性、资源路径和文件校验，以及幻形的候选过滤、取消、嵌套事件等待、濒死去重、轮回四类候选和删除选项等模拟流程。

另有可选的手机源码数据核查脚本，使用方式见 [测试说明](tests/README.md)。本仓库没有上传手机本体源码快照。

截至 2026-11-03，用户已反馈：技能语音正常；幻形不再报错；濒死至获救共发动两次变幻；轮回已测试，未发现问题。具体模式、两名武将及四类选项的逐项覆盖范围没有单独记录。模拟测试与上述手机反馈分别记录，未据此声明所有第三方技能组合或联机模式均已验证。当前代码不提供国战选将。
