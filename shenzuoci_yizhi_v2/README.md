# 神左慈移植 1.1.0

本目录是游戏扩展目录，名称必须保持 `shenzuoci_yizhi_v2`。

包含神左慈、神左慈改，以及变幻（含新生）、幻形和轮回。原技能与素材来自“汤圆精品包”。

首次安装：将本目录复制到无名杀本体的 `extension` 下，确保最终入口为 `extension/shenzuoci_yizhi_v2/extension.js`。完全重启游戏，启用“神左慈移植”，再重启并搜索武将。

更新：只备份和覆盖需要更新的具体文件，随后完全重启游戏。本次适配参考为 Android 无名杀 1.11.5.2。

完整功能与安装说明见仓库根目录 [README](../README.md)；开发说明见 [编程注意事项](../docs/无名杀扩展编程注意事项.md) 和 [轮回设计](../docs/轮回技能设计与术语.md)。

骨骼动皮适配及专用阵亡语音暂未加入。原头像和四段变幻语音保留原始字节。
